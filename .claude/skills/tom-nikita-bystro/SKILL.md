# Серия по команде «давай следующую тему» — коротко и без лишних токенов

## 0. Тема
Первая строка таблицы `tom-nikita-temy/trends.md` §6 без пометки «сделана». После выпуска — дописать в её строку «**сделана — эп. N**».
Факты: 2–3 `WebSearch` (mode "standard") **одним сообщением**, по 2 источника на цифру. Формулировки — осторожные.

## 1. Что читать (и только это)
- `CLAUDE.md` (уже в контексте) + этот файл.
- Голос героев: 1 серия из `tom-nikita-kanal/scripts.md` (`grep -n "EP11" -A25`), не весь файл.
- **Эталон кода — ep11**: `hf/episodes/ep11/{set.js,scenes.js,sound.json}` (≈ 250 строк вместе) — копировать структуру, менять декорацию/вставки/CUE. Чужие серии и `chars.js`/`props.js`/`engine.js` не читать; сигнатуры — `grep -n "function имя" hf/engine2/*.js`.
- Ловушки: `label(x, y, текст, 0, цвет, rot, size)` — 4-й аргумент ширина (0), не цвет; свет — `morningLight(t)`-подобная функция берёт `t`; аббревиатуры в `tts` — как говорят (`сэ-шэ-а́`).

## 2. Стандарт сценария (одобрен владельцем на эп. 11)
- 150–175 слов, 55–65 с. 15 реплик: n01 хук-последствие, объясняющий ситуацию (предмет + цифра: «корм за $40 — а он не ест»).
- t01 — переворот одной фразой + кошачья шутка («…курица, кукуруза и надежда»).
- 3 факта лестницей (каждый — вставка), между ними короткие реакции Никиты (2–5 слов).
- Визуальный «поворот» на 3-м факте (мелкий шрифт, завод, лупа).
- «Что делать» — один простой шаг + кошачья логика Тома («Я хищник, а не хомяк»).
- n07 — неправильный вывод, логичный для Никиты (та же ошибка в новой форме) → `after: 1.2` → t07 мат Тома + кошачья добивка → t08 «Подпишись, кожаный. <добивка по теме>».
- **Удержание (обязательно):** `tom-nikita-scenarij/uderzhanie.md` §2–§9 и самопроверка §12 (порог 8,5) — незакрытый вопрос хука, заблуждения голосом Никиты, повторные хуки, число-сувенир, мат-колбэк.
- **Новое из исследования:** вопрос зрителю в описании/на экране финала («Переверни свою пачку — что первое?»), название по формулам trends.md §5.

## 3. Стандарт визуала (не ниже ep11)
Декорация (функция `<место>(t, o)` в set.js), обязательно:
1. стена с узором/фактурой + панели/плинтус;
2. окно или проём с 2–3 планами (небо полосами, солнце+`glowAdd`, облака и птицы в движении по `t`, дома с огнями);
3. 5+ бытовых мелочей на уровне героев (кружка с паром, книги, часы `clockP`, цветок, коврик, игрушка, носок на батарее);
4. свет: `lightmap(амбиент ≥ #c0b0a8, …)` + `radial` от источника + `cone` луч + пятна/пылинки;
5. живое: что-то движется всегда (пар, облака, листья, птицы).
Вставки — на фактурном фоне (`tableBg` из ep11, `cork()`), с `tape`/`pin`, источник — `label(...)` на плашке, не голым текстом.
Цвет: `const GRADE = { sat: 1.35, con: 1.07, bri: 1.03 };` в scenes.js. Темп: `tempo` Том 1.15, Никита 1.12. Сцены — 2.5D по образцу ep12 v2 (`cam25.js`, `emo.js`, переходы, гэг Тома, предметы у Никиты), звуки CC0 (`tools/sfx_fetch.py`).
Камера общего плана: оба героя целиком, Никита не у края (`NIKP.x ≈ 380`, общий `cx ≈ 600, z ≈ 1.28`).

## 4. Команды (по одной на шаг)
```bash

.venv/bin/python pipeline/voice_v2.py episodes/epNN_x | tail -2 && python3 pipeline/words.py episodes/epNN_x
# сцены: mkdir hf/episodes/epNN; episode.json как у ep11; set.js/scenes.js/sound.json — Write целиком
cd hf && python3 tools/mkpage.py epNN >/dev/null && node tools/dbg.cjs build/epNN/film | tail -2 && tools/make.sh epNN snap <20–25 моментов> | tail -2
# Read build/epNN/snaps/sheet.jpg один раз + 1 кадр общего плана в полном размере; правка; rm -rf build/epNN/snaps; переснять только изменённое

```
