# «Ночной графит» — мультики кодом (Том и Никита)

Всё рисуется кодом: HTML canvas + JS, всё считается от времени `t`, рендер — HyperFrames (24 к/с). Генеративные картинки и видео **не использовать** (решение владельца). Голос — ElevenLabs (готовый, его не трогаем без просьбы).

## ДНК стиля
- Рисунок на двойках: линии «кипят» 12 раз/с (`FRAME = floor(кадр/2)` — зерно всех случайностей), камера и движение — 24 к/с.
- Рваная линия-лента с нажимом (`pencil`): сужение на концах, случайный разрыв, второй тонкий проход, замкнутые контуры заходят за начало.
- Штриховка вместо заливки (`hatch`, `crayon`): на тёмной бумаге штрихуем **свет** (`litFade` — плотность к источнику).
- Бумага угольная, потёртая: пятна, волокна, следы ластика, призрачные линии, зерно «съедает» мел.
- Строительные линии в начале наброска (`guides`) гаснут.
- Свечение — только акценты: глаза Тома, молоко, наука, тревога. Контровой свет по контуру (`rim`).
- Палитра = бумага + роли (`PALS` в `hf/engine/engine.js`, тема `night`; есть `chalk`, `blueprint`). До поворота — холод, после — тепло.
- Переходы — камерой и морфингом (`morphPts`), без моушн-блюра. Цепочка: последний объект сцены = первый следующей.

## Персонажи (`hf/engine/chars.js`)
- **Том** `tom(o)`: огромный вислоухий табби, грива, светлая морда, кислотно-зелёные светящиеся глаза, прищур `lid 0.42`, сидит «лапка на лапке». Параметры: `x y s t yaw tilt lk lid pup brow smirk m paw pawX pawY mood('smug'|'bliss'|'shock'|'angry') fluff light glowE body`.
- **Никита** `nikita(o)`: сутулый парень, кудри, нос с горбинкой, щетина, синее худи. Параметры: `yaw tilt lk lid brow browA smile m mood('eww'|'shock'|'dumb'|'angry'|'sick') arms{l,r:[локоть, кисть, поза, слой]} legs('stand'|'sit'|'crouch') lean light`.
- Рот — `mouthAt(кто, t)` по виземам Rhubarb из `LINES` (data.js). Моргание — `blinkAt`.
- Листы персонажей и стиль — в Claude Design (артефакт «Том и Никита — библия персонажей»), исходники картинок — `hf/episodes/design`.

## Порядок работы над эпизодом
1. Сценарий 50–80 с, факты проверены; хук в 1-й секунде; поворот на 35–45 % длины; последние 3 с — постер.
2. Озвучка → `pipeline/voice_v2.py` (темп, паузы, слова Whisper, виземы Rhubarb) → `voice.wav` + `timeline.json`.
3. Раскадровка `hf/episodes/<эп>/storyboard.md`: время / что нарисовано / камера / звук.
4. Сцены `hf/episodes/<эп>/scenes.js`: метки `CUE` **только от слов** (`Wd(реплика, индекс)`), таблица `SC`, по функции на сцену, `post` (грейдинг), `hudFrame` (субтитры, обложка, постер).
5. Проверка кадров: `tools/render.sh <эп> snap 0,3.5,12` → `build/<эп>/snaps/sheet.jpg`. Смотреть: читается без звука, субтитры ≥ 56 px заглавной (Oswald 84), ничего важного ниже 1632 px, первый кадр — обложка, последний — постер, ничего не прыгает, свечения не перебор.
6. Звук `hf/tools/sound.py`: музыка нотами (бас, Rhodes, щётки, арпеджио, Karplus–Strong), шумы по тем же `CUE` (`tools/cues.cjs` выгружает их со страницы). Итог −15 LUFS, пик ≤ −1 dBFS, музыка под голосом с дакингом.
7. Полная сборка: `hf/tools/render.sh <эп>` → `build/<эп>/final.mp4` и `chat.mp4` (< 29 МиБ). Проверить длину, 24 к/с, звук, последний кадр.

## Грабли
- Индексы слов: тире «—» из реплик выкинуты (`Wd` считает без них). Проверять индексы печатью слов, а не на глаз.
- Все случайности — из `rng(hsh(FRAME, ...))` и до любых условий; `Math.random` запрещён (прыгает между кадрами).
- `txt(..., { a: 0 })` должен гаснуть целиком, включая свечение (исправлено в движке — не возвращать).
- Объекты, которые нужно «держать», ставить от координат кисти (`DRINK()` в ep01), иначе стакан висит в воздухе.
- Длинная лапа Тома выглядит палкой: `pawX ≈ 120–160`, `pawY ≈ 130–270`.
- Сменилась длина озвучки → пересобрать `cues.json` и звук (`render.sh` делает сам).
- Рендер ~1 с/кадр на 4 воркерах: 80 с ролика ≈ 35–45 мин; контрольные кадры — секунды.
