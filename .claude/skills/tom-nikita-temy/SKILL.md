# Темы для «Тома и Никиты»

## Два формата
- **Б — «Все всю жизнь делали неправильно».** Массовая привычка, которую опровергает сам производитель, регулятор или исследование (рис для мокрого телефона, мытьё курицы, закрывать приложения). Это основной формат.
- **А — «Бытовая конспирология».** «Они нас…» — слух, который проверяется и оказывается либо мифом (телефоны слушают), либо правдой с неожиданной стороны (кот манипулирует мурчанием на 380 Гц).

## Фильтр темы (все пункты — «да»)
1. У каждого зрителя есть **личный опыт** («я так делал») — тогда будут спор в комментариях и пересылки.
2. Опровержение — **документ, а не мнение**: страница поддержки, регулятор, рецензируемая статья. Минимум 2 независимых источника на каждый факт.
3. Опровержение умещается в **1 миф + 2–3 факта** и одно практическое «как надо».
4. Есть **визуальное последствие для хука** (мёртвый телефон в рисе, кухня в брызгах, пластырь на пальце от смахиваний).
5. Есть **естественный панчлайн**: Никита всё понял неправильно («Значит, в гречку!»), и Том срывается.

## Стоп-темы
- Политика, война, «иноагенты», религия, национальности (кейс «Масяни», октябрь 2026).
- Медицина без регулятора-первоисточника на экране. Никаких «лечебных» советов.
- Советы по ремонту, где можно навредить (разобрать, протереть спиртом).
- Бренды: не копировать логотипы. Цитату даём вырезкой с текстом.

## Проверка фактов (перед сценарием)
- Цифры берутся только из первоисточника. «Из пересказа» — либо проверить, либо не использовать.
- Записать формулировки, которые нельзя говорить: например, не «рис не впитывает», а «производители советуют воздух, а не рис».
- Свериться со шкалой риска: низкий (техника, быт, коты), средний (еда — только через регулятора), высокий (здоровье — не берём).
