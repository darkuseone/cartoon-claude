## 3. Выводы для сценариев
1. **Кот — наш главный актив.** В нише «умный кот объясняет» почти никто не делает сюжет-ситком с постоянными героями. Минимум каждая 3-я серия — про котов или с кошачьей выгодой Тома (корм, лоток, мурчание, «кот тебя любит?»).
2. **Хук = последствие + предмет в кадре + цифра.** «Корм за $40 — а он не ест», «Пачка та же — а чипсов меньше». Не «Правда ли, что…».
3. **Заголовок-вопрос с конкретикой**: «Сколько лосося в корме „с лососем“?» лучше, чем «Корм — развод?». В первой реплике — ответ на «про что ролик».
4. **Повороты каждые 8–12 с** (в топовых роликах ниши — каждые 6–8 с): вставка, новое слово/цифра, реакция Никиты. Длина 55–65 с — сладкая зона по досмотру.
5. **Лестница/сравнение** (95 → 25 → 3 → 0 %) — сильный визуал для пересылки: зритель скриншотит.
6. **Финальный неправильный вывод Никиты** — повторение той же ошибки в новой обёртке; он и есть «пересылочный» момент.
7. **Название** до 50 знаков, без «правда или миф», с объектом и цифрой; хэштеги по теме, без мусора (на канале Markus Brown теги «2050 мир», «эра 2050» не помогли).
