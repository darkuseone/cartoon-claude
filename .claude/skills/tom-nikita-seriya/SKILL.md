# Новая серия под ключ

Сначала (если ещё не в контексте): `tom-nikita-kanal` (направление и голос героев), затем по шагам ниже. Остальные скиллы открывать на своём шаге.
Окружение нового контейнера: `bash tools/setup.sh` (один раз).

## Маршрут (≈ 12–15 вызовов инструментов на серию)

**1. Тема и факты** (`tom-nikita-temy`)
- Тема от пользователя или из бэклога (`tom-nikita-temy/backlog.md`, таблица в SKILL.md).
- 2–3 **WebSearch "standard" одним сообщением** (параллельно): по факту на поиск. Каждую цифру — минимум 2 источника; спорное — формулировать осторожно («опрос», «до», «вину не признала»).

**2. Сценарий** (`tom-nikita-scenarij`, образцы — `tom-nikita-kanal/scripts.md`)
- 110–150 слов, 10–15 реплик, формула канала. Ключи `n01…`, `t01…`. Пауза `after: 1.2` перед матом, `0.4` после.
- Без омографов (мою, замок, плачу…). Деньги словами «долларов». Ударения `́` в трудных словах.
- Записать `episodes/epNN_<слово>/script.json` питоном (заголовок, голоса, tempo — копия из `episodes/ep08_bulb/script.json`).

**3. Озвучка** — одной командой Bash:
```bash
python3 pipeline/tts.py episodes/epNN_x && .venv/bin/python -I pipeline/transcribe.py episodes/epNN_x/vo/*.mp3
```
Проверить: нет прочитанных тегов «[…]», слова на месте (ошибки расшифровки вроде «спортзавы» — не страшно). Плохую реплику — перегенерировать: `tts.py episodes/epNN_x t03`.

**4. Таймлайн** — одной командой:
```bash
.venv/bin/python pipeline/voice_v2.py episodes/epNN_x && python3 pipeline/words.py episodes/epNN_x
```
Итог > 60 с → поднять `tempo` (tom 1.14, nikita 1.1) и/или ужать `after`, пересобрать (без новой озвучки).

**5. Декорация и сцены** (`tom-nikita-kod`, справочник `tom-nikita-kod/api.md`)
- Выбрать ближайший образец по позе: стоит у столешницы — `ep03`/`ep07`; сидит за столом — `ep04`; стоит на табуретке/предмет вверх — `ep08`; комната с кроватью — `ep06`; улица/балкон — `ep05`.
- `set.js` — **новая** декорация (другая комната/время суток/палитра) + 4–6 вставок, по одной на факт. Писать файл целиком через Write, не читая образец полностью: `grep -n "^function" hf/episodes/epXX/set.js` и точечно 20–40 строк.
- `scenes.js` — по шаблону из `CLAUDE.md` §4: CUE (индексы из words.py), SHAKES, EP, позиции, `scene()`, SHOTS (смена каждые 2–4 с), SH (cold, крупные, вставки, `stare` перед матом, `mat`, `final` с петлёй).
- `episode.json`: `{"engine":"engine2","timeline":"../episodes/epNN_x/out/timeline.json","scripts":["set.js","scenes.js"]}`.

**6. Проверка кадров** — одной командой: `mkpage + dbg + snap` на 20–25 моментов (каждая склейка + ключевые слова):
```bash
cd hf && python3 tools/mkpage.py epNN >/dev/null && node tools/dbg.cjs build/epNN/film | tail -2 && tools/make.sh epNN snap 0.5,2.5,…
```
Read `build/epNN/snaps/sheet.jpg` **один раз**, пройти чек-лист `CLAUDE.md` §6, исправить всё одной правкой, переснять **только** изменённые моменты (`rm -rf build/epNN/snaps` перед снимком).

**7. Звук** — `sound.json` по образцу серии-донора (метки = имена CUE), `tools/make.sh epNN sound`. Цель: музыка −14…−19 LU, шумы −11…−13 LU. Не попало — поправить `levels` один раз (больше шумов → `fx`↑ и наоборот).

**8. Рендер** — в фоне (`run_in_background`), ~15 мин:
```bash
cd hf && tools/make.sh epNN all epNN_x > build/epNN/make.log 2>&1; echo "exit $?" >> build/epNN/make.log; grep -E "exit|длительность" build/epNN/make.log
```
Пока идёт рендер: `publish/epNN_x.txt` (скилл `tom-nikita-vykladka`), строка в таблицу `CLAUDE.md` §2 и `tom-nikita-temy/SKILL.md`, `python3 tools/gen_refs.py`. Можно рисовать следующую серию (не рендерить две одновременно).

**9. Приёмка** — Read `out/epNN_x_sheet.jpg`; при сомнениях в произношении — `transcribe.py` по куску звука (`ffmpeg -ss … -t …`). Затем коммит, пуш ветки, **fast-forward в master**, пуш master (`git checkout master && git merge --ff-only <ветка> && git push origin master && git checkout <ветка>`). Отправить видео пользователю (SendUserFile).

## Готово, когда
- Видео ≤ 60 с, < 28 МиБ, `exit 0`, контакт-лист без обрезанных плашек и перекрытых субтитров.
- Факты проверены, мат 1–2 раза и только звуком/со звёздочкой, `$` вместо других валют, нет употребления табака/алкоголя.
- Новая декорация, петля в финале, «Перешли тому, кто…».
- Есть `publish/epNN_x.txt`, обновлены `CLAUDE.md` §2, `tom-nikita-temy`, справочники (`gen_refs.py`), всё в master.

## Экономия токенов
- Не читать целиком `chars.js`, `props.js`, `engine.js`, чужие `set.js`/`scenes.js` — есть `tom-nikita-kod/api.md` и `grep -n`.
- Склеивать шаги в один Bash через `&&`; правки файлов — питон-заменой или Edit, без повторного Read только что записанного.
- Смотреть один контакт-лист вместо отдельных кадров; переснимать только изменённые моменты.
- Не опрашивать рендер циклом — ждать уведомления фоновой задачи.
- Несколько серий подряд: сначала сценарии и озвучка всех, потом сцены и рендеры по очереди (одна рендерится, следующая рисуется).
