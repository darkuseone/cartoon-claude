# Правки готовой серии

Сначала найти серию в таблице `CLAUDE.md` §2 (папки озвучки, сцен, видео). Принцип: **минимальная цепочка** — перегенерировать только то, что зависит от правки.

| Правка | Цепочка |
|---|---|
| Слово/фраза/произношение реплики | `script.json` (`text` + `tts`) → `tts.py <папка> <ключ>` → `transcribe.py` этой реплики → `voice_v2.py` → `words.py` (сверить, что индексы слов в `CUE` не съехали; поправить `CUE`) → snap затронутых моментов → `make.sh <эп> all <имя>` |
| Ударение в омографе (мою, замок…) | знак `́` не помогает → перефразировать реплику (см. строку выше) и записать слово в `tom-nikita-scenarij` |
| Картинка/плашка/персонаж/цвет | `set.js`/`scenes.js` → snap **этого момента** (по скриншоту найти время: субтитр на скрине → `words.py`) → `make.sh <эп> all <имя>` |
| Только громкость музыки/шумов, звук эффекта | `sound.json` → `make.sh <эп> sound` (смотреть LU) → `make.sh <эп> mux <имя>` (без рендера, если в контейнере есть `hf/build/<эп>/video.mp4`, иначе `all`) |
| Убрать мат совсем | `make.sh <эп> clean <имя>` → `out/<имя>_clean.mp4` (запикан по `bleep`) |
| Изменение движка (`engine2/*.js`) | меняет **все** серии → перерендеривать старые только по просьбе владельца |

## Порядок
1. Подтвердить по скриншоту, что именно не так (не переспрашивать, если понятно).
2. Внести все правки серии за один проход, снять один контакт-лист нужных моментов, Read.
3. Рендер в фоне; после — Read `out/<имя>_sheet.jpg`, при правке звука — `transcribe.py` по куску (`ffmpeg -ss <с> -t <с> -i out/<имя>_chat.mp4 -ac 1 -ar 16000 файл.wav`).
4. Коммит → пуш ветки → fast-forward `master` → пуш → отправить видео (SendUserFile) с подписью «что исправлено».
5. Если правка — общее правило (а не разовая ошибка), записать его: `CLAUDE.md` §7 «Уроки» и нужный скилл. Так ошибка не повторится в следующих сериях.

## Уже принятые правила из правок (не нарушать)
Сигарета → закрытая пачка; вейп → коробка; ₽ → `$`; «мою» → «отмываю»/«не мыть»; текст в плашке — по ширине; субтитры на y 1440; русские площадки не нужны; генеративные картинки не использовать; предмет реально подносится ко рту/руке.
