# Код сцен: рецепты и грабли

Справочник функций — `api.md` (генерируется `python3 tools/gen_refs.py`). Не читать большие файлы целиком: `grep -n "function имя" hf/engine2/*.js` + 5–10 строк.
Кадр 1080×1920, мировые координаты = экранные при `cam(540, 960, 1)`. Порядок отрисовки = слои: фон → декорация → `layer(Том)` → `layer(Никита + предмет)` → передний план → `lightmap` → оверлеи (микробы, вспышки).

## Геометрия персонажей
| | Масштаб | Опора | Формула |
|---|---|---|---|
| Том сидит | `s: 0.62` | верх поверхности `Y` | `TOMP.y = Y − 385·0.62 ≈ Y − 239`; ширина тела ±125, хвост справа до +165 |
| Никита стоит (`legs:'stand'`) | `s: 0.95` | пол `F` | `NIKP.y = F − 508·0.95 ≈ F − 483` |
| Никита сидит (`legs:'sit'`) | `s: 0.95` | сиденье ≈ `y + 345` | ноги до `y + 546·0.95` |
| Рука Никиты | — | `arms.r = [hx, hy, поза]` от центра головы | мир: `[NIKP.x + hx·0.95, NIKP.y + hy·0.95]` |

Типовые позиции: Никита `x 300–420`, Том `x 830–900` (Том справа и выше, смотрит `lk:[-0.8, 0]` влево на Никиту; Никита `lk:[0.8, 0]` вправо).
Позы рук: опущена `[-150, 300, 'open']`; держит предмет у груди `[190, 110, 'fist']`; вверх `[150, -230, 'fist']`; указывает `[150, -30, 'point']`; руки в стороны `[±190, 60, 'open']`; телефон `[-30, 196, 'phone']`.

## Камера (`cam(cx, cy, z, rot, shake)`, всегда закрывать `pop()`)
- Общий: `z 1.25–1.3`, центр между героями (`cx ≈ 600–640`).
- Крупный Никита: `cam(NIKP.x, NIKP.y + 70, 2.0)`; крупный Том: `cam(TOMP.x, TOMP.y + 80, 2.2–2.5)`.
- Вставка: `cam(540, 960, 1)` + `slideIn(u, () => …)`.
- «Наезд» на ключевом слове: `z` больше после `CUE` (`t > CUE.x ? 2.4 : 2.2`). Тряска: `SHAKES [[t, длит, сила]]` + `cam(..., shakeAt(t))`.

## Где ставить надписи (экранные y)
- Заголовок серии: 230–380 (common.js, пока идёт первый план).
- Удар/мат/цифра — `ransom(...)` на `y 300–330`, размер 100–170.
- Призыв в финале: две строки `y 300` (92 px) и `y 430` (72–80 px).
- Подпись на вставке: `label(540, 1240–1300, текст, 0, цвет, rot, 36–56)`. **Ниже 1330 — нельзя** (субтитры на 1440).
- Источник мелко: `txt(..., 540, 1200–1320, 26–28, …)`.

## Рецепты
- **Предмет в руке:** в `scene()` внутри того же `layer`, после `nikita(...)`: `const [hx, hy] = handW(n.arms.r); предмет(hx + dx, hy + dy, s, rot)`. Примеры: `chicken` (ep07), `pack` (ep05), `bulbP` (ep08), `foodBag` с сыплющимся кормом (ep06).
- **Вставка-факт:** `cork()` или `bg('#цвет', seed)` → `card(...)`/реквизит → цифра `ransom` с `reveal: pr(t, c.x, c.x + 0.3), pop: true` → штамп (`stampX`, рамка `piece(..., {raw:true, lc:'#c8241c', lw:9})` + `txt`) → источник мелко.
- **Список советов:** `tips7` (ep07) / `tipsInsert` (ep04) — 3 карточки, появляются по CUE слов.
- **План перед матом:** `stare` — статичный крупный Том, `lid 0.62`, без речи, 1–1,3 с; затем `mat` — `z` чуть больше, `lid 0.85–0.9`, `brow −0.8`, тряска, `ransom('С*КА', 0, 0, 170, …)` на `y 330`, `EP.hideMat` прячет субтитр.
- **Финал-петля:** `final` — общий план, Том с лапой `paw:1, pawX:175, pawY:110` на «Подпишись», к `CUE.loop` герои встают в позу первого кадра.
- **Свет:** `lightmap(амбиент, () => { radial(...) })`. Амбиент не темнее `#8a8aa0` (иначе каша). Ночь — сине-фиолетовый амбиент + тёплые `radial` от ламп; день — `#d9cdbd`. Вспышка — временно `lit = 2` на 0,2 с (ep08 `flash`).
- **Оверлей-эффект** (микробы, искры): после `lightmap`, `glowAdd` + `ellP` (ep07 `microbes`). В крупных планах не сыпать на лицо.
- **Экран телефона:** `phoneCut(x, y, s, rot, { screen: () => { …координаты −96..96 × −190..190… } })`.

## Звук (`sound.json`)
Копировать у серии-донора, менять метки. Типы музыки: `groove` / `pluck` / `tension` / `night` (`from`, `to`), `stop` и `endsting` (`at`). SFX: `slam pop click whoosh paper tear scratch buzzer bubbles chomp snip clink bell blip foil sniff purr chirp thud ticks hum riser gurgle gulp door meow`. Метка — `"имя"`, `"имя±сек"` или число. `bleep` — для запиканной версии.

## Грабли (уже наступали)
| Симптом | Причина → решение |
|---|---|
| `Identifier 'X' has already been declared` | имя уже есть в common.js/page.html (`P`, `WS`, `SC`, `GROUPS`…) → переименовать, `SH` вместо `P` |
| Шрифт не применился, текст мелкий | семейство с цифрами без кавычек → `font: "'Courier 10 Pitch'"` |
| Текст вылез из плашки | ширина `card` мала → `label()` (сам считает) или ширина ≥ символы × размер × 0,62 + 80 |
| Плашка/ransom на субтитрах | y > 1330 → поднять |
| Предмет «за рукой» | рисовать после рукава, в том же `layer`, в точке кисти |
| Стакан «прикладывается к лицу» | целиться в рот: смещение по наклону головы (ep01v4 `drink`) |
| Сцена чёрная | амбиент `lightmap` слишком тёмный → поднять |
| `tomHead` падает | передать `m: { open, round }` |
| `cues.cjs`: метки нет | в `sound.json` имя, которого нет в `CUE` |
| Шумы −19 LU / музыка −9 LU | одиночный громкий `slam` нормирует шину → поднять/опустить `levels.fx`/`music` |
| Озвучка: ударение в омографе | не лечится знаком `́` → перефразировать реплику |
| Ролик > 60 с | `tempo` 1.14/1.1, меньше `after`, сократить реплику |
