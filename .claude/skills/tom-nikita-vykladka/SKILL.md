# Выкладка

Готовые файлы — `publish/ep01_milk.txt … ep08_bulb.txt` (образец формата), оформление канала — `publish/channel.txt` (ник, слоган, описания, био, аватар/шапка, порядок, график, правила).

## Новая серия → `publish/epNN_<слово>.txt`
Скопировать структуру любого файла серии и заменить:
- **ВИДЕО** — `out/epNN_<слово>_chat.mp4`; **ТЕМА** — вопрос серии.
- **YouTube:** название ≤ 100 знаков: `<Вопрос/интрига> #shorts` (без мата, без кликбейт-лжи). Описание: 2–3 предложения про конфликт (хук + что узнаешь) → «Коротко по фактам:» с цифрами и источниками (год, организация) → призыв «Перешли тому, кто… 👇» → `#томиникита #мультик #анимация` + 4–6 тематических русских хэштегов + `#shorts`. Поле «Теги»: через запятую. Настройки: «Не для детей», категория «Комедия», язык русский.
- **TikTok:** одна строка «вопрос 🐱 призыв 👇» + хэштеги канала, 4–6 русских, 2–3 английских, `#fyp`.
- **Instagram:** вопрос, описание (как в YouTube), призыв, хэштеги канала + темы + `#reels`. Загружать оригинал, не скачанный из TikTok.

## Правила
- Мат — только в звуке ролика. В названии, описании, хэштегах, на обложке — никогда.
- Деньги — `$`. Факты в описании — те же, что в ролике, с годом и организацией.
- Призыв — «Перешли тому, кто <делает ошибку из серии>» (пересылки — главный сигнал Reels).
- Метка ИИ: мультик нарисован кодом, голоса синтезированы — для нереалистичной анимации YouTube метку не требует; если площадка спросит про синтетический голос — отметить.
- После новой серии дописать её в порядок публикации в `publish/channel.txt` (табачную и другие чувствительные темы — ближе к концу).
